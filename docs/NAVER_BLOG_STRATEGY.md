# 네이버 블로그 조회수 개선 전략 (2026-11-11)

> 목표: **네이버 블로그 조회수만** 올린다. 이 사이트(`my-news-blog.pages.dev`)와 Blogger는 원고 작성·보관용 도구로 본다.
> `TRAFFIC_ANALYSIS_2026-11.md`는 구글 기준 분석이다. 특히 그 문서의 "네이버에는 요약+링크만 올려라" 권고는 **이 문서로 대체한다(반대로 해야 함)**.
>
> 주의: 네이버 블로그 통계·글 목록은 저장소에 없어서 보지 못했다. 아래 원인은 발행 구조와 원고(4,209개)를 보고 추정한 것이다.
> 7장 방법으로 직접 확인하길 권장한다.

## 1. 네이버 기준 핵심 원인

### ① 네이버에 올리기 전에 같은 글이 다른 곳에 먼저 공개된다 → "유사문서" 판정
현재 순서는 이렇다.

```
초안 → Blogger 자동 발행 → 이 사이트 자동 발행 → (나중에) 네이버에 수동 붙여넣기
```

네이버 검색로봇은 Blogger와 일반 웹사이트도 수집한다. 같은 글이 이미 수집돼 있으면 **나중에 올라온 네이버 글이 복사본으로 판정**되어
검색에서 빠지거나 아래로 밀릴 수 있다. 이런 글이 쌓이면 블로그 전체 신뢰도(C-Rank)도 같이 떨어진다.
조회수가 계속 줄어드는 가장 유력한 원인이다.

### ② 주제가 너무 흩어져 있다
원고 분야가 IT·스포츠·패션·정치·연예·경제·건강·자동차 등 11개다. 네이버 C-Rank는 **한 주제를 꾸준히 깊게 쓰는 블로그**를 높게 평가한다.
"모든 뉴스를 다루는 블로그"는 어느 주제에서도 전문 블로그로 인정받기 어렵다.

### ③ 뉴스 재가공 글은 네이버에서 노출 자리가 거의 없다
네이버에서 이슈 키워드를 검색하면 상단은 뉴스 탭·언론사·인플루언서 영역이 차지한다. 일반 블로그가 노출되는 자리는
**경험·정보형 글**(D.I.A.+ 모델이 선호하는 글)이다. 기사 내용을 다시 정리한 글은 이 기준에서 점수가 낮다.

### ④ 언론사 사진을 그대로 쓴다
원고 이미지의 63~87%가 언론사 기사 사진이고, 상당수는 몇 년 전 사진이다. 네이버는 이미 공개된 같은 이미지를 알아보며,
언론사가 저작권 신고를 하면 게시중단이 걸리고 누적되면 블로그 전체가 불리해진다.

### ⑤ AI 원고를 대량으로 올렸다가 줄였다
4월에는 원고가 하루 51개였고 지금은 7개다. 네이버에 올리는 양도 비슷하게 움직였다면, 짧은 기간에 비슷한 형식의 글을 대량으로 올린 것 자체가
저품질(검색 누락) 신호가 될 수 있다. 그 뒤로 글 수까지 줄었으니 조회수가 이중으로 빠진다.

## 2. 이번에 저장소에서 수정한 것

| 변경 | 이유 |
|---|---|
| `static/robots.txt`: **네이버 검색로봇(Yeti) 차단** | 이 사이트 글이 네이버 블로그보다 먼저 수집되는 것을 막아 네이버 글이 원본으로 인정받게 한다 |
| 글 페이지에 **"네이버 블로그용 복사" 도구** 추가 | 기존 방식(Cmd+A 전체 선택)은 관련 글·면책 문구·좋아요 버튼·외부 링크까지 같이 붙여넣어졌다. 이제 버튼으로 **제목 / 본문 / 태그(최대 10개)** 를 각각 복사한다. 본문의 링크는 글자만 남기고 외부 링크는 지운다 |
| 최근 7일 같은 이슈 중복 게시 차단 (지난 작업) | 네이버에서도 같은 키워드 글을 여러 개 올리면 서로 경쟁하고 유사문서로 묶인다 |

### 복사 도구 사용법
1. 원하는 글 주소 뒤에 `?copy=1`을 붙여 한 번 연다. 예: `https://my-news-blog.pages.dev/2026-11-03-김하성퀄리파잉오퍼.html?copy=1`
   → 이후로는 그 브라우저에서 모든 글에 초록색 도구가 보인다. 일반 방문자에게는 보이지 않는다. 끄려면 `?copy=0`.
2. **제목 복사** → 네이버 에디터 제목칸에 붙여넣기
3. **본문 복사** → 본문에 붙여넣기 (서식·소제목·이미지 유지)
4. **태그 복사** → 태그 입력칸에 붙여넣기

> 언론사 이미지는 붙여넣은 뒤 **직접 만든 이미지로 바꾸는 것**을 권장한다(4장 참고).

## 3. 발행 구조 바꾸기 (가장 중요)

| 지금 | 바꿀 것 |
|---|---|
| Blogger에 같은 글 자동 발행 | **중단**하거나, 네이버에 올리고 최소 하루 뒤에 문장을 크게 바꿔서 올린다. Blogger는 네이버가 수집하므로 robots로 막을 수 없다 |
| 이 사이트 자동 발행 | 유지 (Yeti 차단을 적용했으니 원고 보관·복사용으로만 사용) |
| 네이버는 맨 마지막에 붙여넣기 | **네이버가 첫 공개 장소**가 되도록 한다 |
| 하루 7개 이상, 여러 분야 | **하루 1~3개, 1개 주력 주제** |

Blogger 자동 발행은 저장소 밖(`~/blog/scripts/generate_all.sh`, `blogger_post.py`)에 있어서 이번에 수정하지 않았다.

## 4. 글 형식 (네이버용)

```
[네이버 블로그 원고 규칙]
1. 제목: 핵심 키워드를 맨 앞에, 25~35자. 자극적 단어 금지.
   예) "갤럭시 XR 실사용 후기, 비전 프로와 3가지 차이"
2. 첫 문단(2~3줄): 키워드를 넣고, 이 글에서 무엇을 알 수 있는지 바로 말한다.
3. 경험·의견 문단을 반드시 1개 이상 넣는다: "직접 써 보니", "현업에서 보면", "제가 확인한 바로는"
   — 네이버(D.I.A.+)가 가장 높게 평가하는 요소이고, AI 원고와 구별되는 부분이다.
4. 모바일 기준: 문단은 2~3줄, 소제목 3~5개, 본문 1,500~2,500자.
5. 이미지 4~8장. 우선순위: 직접 찍은 사진 > 화면 캡처 > 직접 만든 표·카드 이미지(캔바 등) > 공식 보도자료 이미지.
   언론사 기사 사진, 날짜가 오래된 사진은 쓰지 않는다.
6. 출처는 글 끝에 "출처: 연합뉴스, ○○부 보도자료"처럼 글자로만 적는다(외부 링크 최소화).
7. 같은 이슈 후속 소식은 새 글 대신 기존 글을 수정해서 "추가: 11/12" 식으로 덧붙인다.
8. 태그 5~10개, 핵심 키워드와 연관 검색어 위주.
```

## 5. 주제 선택

네이버는 **블로그 주제 하나**를 정해 꾸준히 쓰는 것이 가장 효과가 크다. 블로그 관리 → 기본 설정 → 블로그 주제도 맞춰 둔다.

| 후보 | 장점 | 단점 |
|---|---|---|
| **IT·XR·AI (추천)** | 현업 XR PM이자 실감AX 대학원생이라 **경험 글**을 쓸 수 있다. 기기 후기, 산업용 XR 도입 사례, AI 툴 사용기, 대학원·논문 이야기까지 확장 가능. 경쟁 블로그 중 전문가가 드물다 | 검색량이 생활정보보다 작다 → 기기·AI 툴 후기처럼 검색량 있는 키워드를 섞는다 |
| 생활 정보(지원금·청약·세금·건강 일정) | 검색량이 크고 꾸준하다 (예: 혼인지원금, 독감백신 접종 시기) | 경쟁이 매우 심하고 경험 요소를 넣기 어렵다 |
| 스포츠·연예·정치 이슈 | 순간 검색량이 크다 | 뉴스 탭·인플루언서에 밀리고, 이슈가 지나면 조회수가 0이 된다 → **줄일 것** |
| 패션 | – | 보도자료 재가공 위주 → **중단 권장** |

### 키워드 고르는 법
1. 네이버 검색광고 → 도구 → **키워드 도구**에서 월간 검색수를 확인한다 (무료).
2. 검색수 1,000~10,000 정도이면서 블로그 탭 상위 글이 오래됐거나 부실한 키워드를 고른다.
3. 실제 네이버 검색 결과에서 **블로그 영역(스마트블록)** 이 보이는 키워드만 쓴다. 뉴스만 나오는 키워드는 블로그 글이 노출되지 않는다.

## 6. 이미 쌓인 글 정리

- 네이버 블로그에서 **조회수 0~1인 뉴스 재가공 글**은 비공개로 돌리는 것을 고려한다(삭제보다 안전). 저품질 글이 많으면 블로그 전체 평가가 낮아진다.
- 같은 이슈를 다룬 글이 여러 개면 가장 좋은 글 하나만 남긴다.
- 언론사 사진이 들어간 글 중 조회수가 나오는 글은 이미지를 직접 만든 이미지로 바꾼다.

## 7. 직접 확인할 것 (네이버 블로그 통계)

1. **통계 → 조회수 추이(일간, 1년)**: 서서히 줄었으면 ①②③⑤, 특정 날짜에 뚝 떨어졌으면 저품질 판정(①⑤) 가능성이 높다.
2. **통계 → 유입분석 → 검색 유입 비율**: 검색 유입이 크게 줄었으면 검색 노출 문제다.
3. **누락 확인**: 최근 글 제목을 큰따옴표로 감싸 네이버 **블로그 탭**에서 검색한다. 내 글이 안 나오거나 다른 사이트(Blogger·이 사이트)가 먼저 나오면 ①이 확정이다.
4. **"site:my-news-blog.pages.dev"** 를 네이버에서 검색해 이 사이트 글이 수집돼 있는지 본다. robots 차단 후 수 주에 걸쳐 빠진다. 빨리 빼려면 네이버 서치어드바이저에 등록한 뒤 수집 제외를 요청한다.
