스마트폰이 항상 마이크를 열어두고 있다는 불안감은 스마트폰 사용자 사이에서 오래된 논란이다. 애플이 이 민감한 주제를 정면으로 다루며 자사 AI 기능의 프라이버시 보호 방식을 공개했다. '상시 청취하되 녹음은 없다'는 주장이 실제로 어떤 구조로 작동하는지가 관심사다.

**애플의 AI 상시 청취 구조**를 간단히 정리하면 이렇다. 기기는 항상 소리를 분석하지만, 그 음성 데이터를 저장하거나 전송하지 않는다. 활성화 명령('Siri야' 또는 버튼 입력)이 확인되기 전까지는 처리된 신호 패턴만 기기 내에서 판단하고 원본 음성은 즉시 폐기된다. 이것이 애플이 말하는 '녹음 없는 상시 청취'의 실체다.

## 온디바이스 AI가 프라이버시를 지키는 방식

![시리GPT 나오나? “애플, 자연어 생성 AI 테스트 중”](https://imgnews.naver.net/image/5110/2023/03/17/0000058462_001_20230317163201218.jpg)

애플은 AI 기능의 상당 부분을 기기 내에서 처리하는 온디바이스 방식을 고수한다. 아이폰 16 시리즈부터 탑재된 A18 칩은 전용 뉴럴 엔진을 갖추고 있어, 음성 인식과 언어 처리 일부를 서버 전송 없이 기기 자체에서 수행한다.

더 복잡한 요청, 예를 들어 긴 문서 요약이나 외부 데이터 접근이 필요한 작업은 클라우드로 전송되지만, 이때도 애플은 **프라이빗 클라우드 컴퓨트(Private Cloud Compute)** 구조를 사용한다. 요청이 처리되면 서버에 데이터가 남지 않고 애플 직원도 내용에 접근할 수 없다는 것이 애플의 설명이다. 이 구조는 외부 보안 연구자들이 독립적으로 검증할 수 있도록 기술 명세를 공개하고 있다.

실제로 어떻게 작동하는지 살펴보면, Siri가 호출 전 마이크 신호를 처리하는 방식은 키워드 스포팅(keyword spotting)이다. 이 기술은 전체 음성을 저장하지 않고, 특정 발화 패턴('Siri야'에 해당하는 음향 특성)이 감지될 때만 실제 처리 파이프라인이 시작된다. 스마트 스피커나 안드로이드 기기도 동일한 방식을 쓰지만, **애플은 이 단계에서 수집되는 원본 신호가 기기 밖으로 나가지 않는다는 점을 명확히 밝혔다.**

iOS 18 기준으로 Siri 요청 이력을 사용자가 직접 확인하고 삭제할 수 있도록 설정이 개선됐다. 어떤 요청이 클라우드로 전송됐는지 로그 형태로 제공하고, 이를 언제든지 지울 수 있다. 사용자가 AI 기능이 수행한 것을 직접 열람할 수 있다는 점에서, 블랙박스처럼 작동하던 이전 방식과 달라졌다.

## 구글·메타와 다른 애플 AI 전략의 배경

구글과 메타는 AI 기능 개선을 위해 사용자 데이터를 수집하고 모델 학습에 활용하는 구조를 기본으로 삼는다. 사용자가 옵트아웃(거부)하면 데이터 수집을 멈출 수 있지만, 기본 설정은 수집 허용이다. 반면 애플은 기본적으로 개인 데이터를 서버에 보관하지 않고 모델 학습에도 사용하지 않는 구조를 표방한다.

이 차이는 비즈니스 모델에서 기인한다. 구글과 메타는 광고 매출이 핵심이어서 개인화된 데이터가 수익과 직결된다. 애플은 하드웨어 판매와 앱스토어 수수료가 주된 수익원이므로, 프라이버시를 제품 차별화 포인트로 활용하는 전략이 가능하다. '프라이버시는 기본권'이라는 팀 쿡의 발언은 단순한 마케팅이 아니라, 수익 구조의 차이에서 나온 일관된 입장이다.

다만 비판도 존재한다. 프라이빗 클라우드 컴퓨트 구조가 실제로 애플의 주장대로 작동하는지 외부에서 완전히 검증하는 것은 제한적이다. 기술 명세를 공개했다고 해도, 실제 서버 환경에서의 동작을 독립적으로 감사하는 것은 여전히 어렵다. 또한 Siri를 통해 제3자 앱이나 서비스와 연동될 때, 해당 서비스가 수집하는 데이터는 애플의 프라이버시 정책 외부에 있다.

챗GPT와의 통합이 iOS 18에서 추가됐는데, Siri가 사용자 요청을 ChatGPT에 전달할 때 어떤 데이터가 OpenAI 서버로 가는지는 OpenAI의 별도 정책에 따른다. 애플은 이 경우 사용자에게 명시적으로 동의를 구한다고 밝혔지만, 연동이 시작된 이후의 데이터 흐름은 애플 통제 밖이다.

AI 기능이 스마트폰에 깊숙이 들어오는 지금, 내 데이터가 어디로 가는지 따져보는 것은 더 이상 기술 전문가만의 관심사가 아니다. 설정 화면 한 번 열어보는 것이 막연한 불안을 줄이는 가장 빠른 방법이기도 하다.

### 애플 AI는 실제로 내 음성을 녹음하나

애플에 따르면, 활성화 명령('Siri야') 이전 단계에서는 음성 원본이 저장되거나 전송되지 않는다. 기기 내부에서 키워드 패턴만 분석하고, 일치하지 않으면 데이터가 즉시 폐기된다. 다만 Siri 명령 이후 처리 과정 일부는 클라우드를 거치며, 이 경우 프라이빗 클라우드 컴퓨트 구조를 통해 처리된 후 서버에 보관되지 않는다고 밝혔다.

### 프라이빗 클라우드 컴퓨트란 무엇인가

프라이빗 클라우드 컴퓨트는 AI 요청이 외부 서버에서 처리될 때도 해당 데이터가 서버에 남지 않도록 설계된 애플의 독자 구조다. 요청이 처리되는 서버는 격리된 환경에서 실행되고, 처리가 끝나면 데이터가 삭제되며, 애플 내부 직원도 접근할 수 없다는 것이 핵심이다. 외부 보안 연구자들이 검증할 수 있도록 기술 명세를 공개 중이다.

### 구글 어시스턴트나 챗GPT 앱과 비교하면 어떻게 다른가

구글 어시스턴트는 기본 설정에서 음성 데이터를 서버에 저장하고, 구글 계정에 음성 기록이 쌓인다. 직접 설정에서 꺼야 한다. 챗GPT 앱은 대화 내용이 OpenAI 서버에 저장되며, 기본 설정에서는 모델 개선에 사용될 수 있다. 애플 AI는 온디바이스 처리와 프라이빗 클라우드 컴퓨트를 기본으로 하여, 서버 저장을 최소화하는 구조가 핵심적인 차이점이다.

AI 편의성과 프라이버시 중 어느 쪽에 더 무게를 두는가. 스마트폰 설정을 열어 Siri 히스토리 설정을 한번 확인해보는 것을 권한다. 여러분은 AI 기능을 쓸 때 내 데이터가 어디로 가는지 신경 쓰는 편인가?
